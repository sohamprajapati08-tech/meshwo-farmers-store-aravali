⚡ Razorpay Real-Time Bank Gateway 100% Anti-Fraud Verified

ℹ️ How to get your Razorpay Keys:
1. Log in to Razorpay Dashboard (dashboard.razorpay.com).
2. In the left sidebar, click Settings → API Keys.
3. Click Generate Key (or Regenerate Key) to get your Key ID and Key Secret.
4. Paste both keys above and click Test Razorpay Connection, then click Save Payment Gateways below.
🛡️ When active, customer orders are verified by Razorpay's bank servers using HMAC SHA256 cryptographic signatures. Fake orders or unverified payments are blocked 100%.

🔗 Google Apps Script Webhook URL

તમારી Google Sheet નું Web App URL અહીં પેસ્ટ કરો. જ્યારે પણ કોઈ નવો ઓર્ડર આવશે ત્યારે તરત જ ઓટોમેટિક Google Sheet માં નવી રો ઉમેરાઈ જશે.

📋 Google Sheets Setup Guide (ફક્ત ૨ મિનિટમાં સેટઅપ)

  1. નવી Google Sheet ખોલો (sheets.new).
  2. ઉપર મેનુમાં Extensions → Apps Script પર ક્લિક કરો.
  3. ત્યાં જે જૂનો કોડ હોય તેને ડિલીટ કરી નીચે આપેલો કોડ પેસ્ટ કરો અને Save (💾) દબાવો.
  4. ઉપર જમણી બાજુ Deploy → New deployment પર ક્લિક કરો.
  5. ડાબી બાજુ ગિયર (⚙️) આઈકોન પર ક્લિક કરી Web app પસંદ કરો.
  6. Who has access માં "Anyone" સિલેક્ટ કરો અને Deploy દબાવો.
  7. તમને મળેલું Web app URL કોપી કરી ઉપરના બોક્સમાં પેસ્ટ કરીને Save Webhook દબાવો!
